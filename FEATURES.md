## 🧠 Intelligence

### Forward Chaining Inference Engine
```
User Inputs → Rule Matching → Scoring Algorithm → Best Match → Personalized Plan
```

### Smart Matching
- **Flexible Conditions** - Handles both single values and arrays
- **Scoring System** - Finds best match even without perfect alignment
- **10 Core Rules** - Covering major fitness scenarios
- **Fallback Plan** - Default recommendation if no strong match

- **7 Variables Collected**
  - Goal (4 options)

## 🎮 User Experience

### Navigation Flow
1. **Sequential Questions** - One at a time, no overwhelm
2. **Auto-Advance** - Click and move (except text inputs)
3. **Back Button** - Available on all screens except first
4. **Progress Bar** - Visual feedback with percentage fill
5. **Question Counter** - "Question X of 7" text display

### Interaction States
- **Hover** - Buttons lift and glow
- **Active** - Green flash on selection
- **Focus** - Red glow on text inputs
- **Disabled** - Grayed out when not applicable

### Responsive Breakpoints
- **Mobile** (< 768px)
  - Stacked layout
  - Full-width buttons
  - Smaller typography
  - Touch-optimized spacing
- **Desktop** (≥ 768px)
  - Centered card (max 650px)
  - Side-by-side buttons
  - Larger typography
  - Hover effects enabled
