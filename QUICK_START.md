# 🚀 Quick Start - Finding the API Settings

## 📍 **Exact Steps to Find API Settings:**

### **Step 1: Open the App**
- Open `index.html` in your browser
- You should see the Flexpert logo and "Step 1 of 7"

### **Step 2: Complete the Assessment**
You MUST complete all 7 questions first:
1. **Workout Goal**: Fat Loss, Muscle Gain, Strength, or General Health
2. **Body Type**: Slim, Average, Broad, or Heavier  
3. **Training Days**: 2-3, 3-4, or 5-6 days per week
4. **Physical Limitations**: None, Upper/Lower injury, or Cardio issues
5. **Workout Environment**: Home or Gym
6. **Intensity Level**: Light, Moderate, or High
7. **Duration**: 10-15, 20-30, or 30-40 minutes

### **Step 3: Get Your Plan**
- Click "Get My Plan" on the final question
- Wait for your personalized workout plan to appear

### **Step 4: Find API Settings**
**NOW you should see the results page with:**
- 🏆 Your workout plan details
- 🟡 "API Key Required" status indicator
- 🔧 **"API Settings" button** ← THIS IS WHAT YOU'RE LOOKING FOR!
- 💬 "Chat with AI Coach" (disabled until you add API key)
- 🔄 "Start Over" button

### **Step 5: Configure API Key**
- Click the **"API Settings"** button
- A section will appear with an input field
- Enter your Gemini API key (starts with "AIza...")
- Click "Save"

## 🔍 **Troubleshooting:**

### **If you don't see "API Settings" button:**
1. **Make sure you completed all 7 questions**
2. **Make sure you clicked "Get My Plan"**
3. **Make sure you're on the results page** (shows your workout plan)
4. **Try refreshing the page and completing the assessment again**

### **Test with Debug Version:**
1. Open `debug.html` in your browser
2. This shows ONLY the API key functionality
3. If this works, the main app should work too

### **Browser Console Check:**
1. Press F12 to open developer tools
2. Go to Console tab
3. Look for any error messages
4. Refresh the page and complete the assessment
5. Check if there are JavaScript errors

## 🆘 **Still Can't Find It?**

If you still can't find the API Settings button:

1. **Try the debug version**: Open `debug.html` - this isolates just the API functionality
2. **Check browser compatibility**: Use Chrome, Firefox, Safari, or Edge
3. **Clear browser cache**: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)
4. **Check JavaScript**: Make sure JavaScript is enabled in your browser

The API Settings button ONLY appears on the results page after completing the full assessment!
